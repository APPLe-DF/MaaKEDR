# 常见问题

## 安装与下载

### 下载的文件名代表什么？

MaaKEDR 的发布压缩包命名格式为：

```text
MaaKEDR-<系统>-<架构>-<版本>-<前端>.<扩展名>
```

例如 `MaaKEDR-win-x86_64-v1.0.2-MFAA.zip` 表示：

- **系统**: `win`（Windows）
- **架构**: `x86_64`（64 位 Intel/AMD）
- **版本**: `v1.0.2`
- **前端**: `MFAA`（图形界面，需 .NET）
- **扩展名**: `zip`

### 下载速度慢怎么办？

GitHub 下载速度受网络环境影响，可尝试：

- 使用 [ghproxy](https://ghproxy.com/) 等代理加速
- 在 MaaKEDR 交流群内获取网盘备份（见 `CONTACT` 文件）

## 运行崩溃

### 启动时提示缺少 DLL（如 `VCRUNTIME140.dll`）

未安装 VCRedist。请下载安装 [vc_redist.x64.exe](https://aka.ms/vs/17/release/vc_redist.x64.exe)。

### MFAA 启动无反应或报 .NET 相关错误

未安装 .NET 桌面运行时。请前往 [.NET 下载页面](https://dotnet.microsoft.com/download/dotnet) 下载并安装对应版本。

### 程序闪退，没有错误提示

检查 `maafw.log` 查看错误日志。常见原因：

- 路径包含中文字符或空格 → 移至纯英文路径
- 解压不完整 → 重新解压
- 杀毒软件误删文件 → 添加排除项

### MXU 版本启动卡顿或黑屏

确保显卡驱动已更新。在 MXU 设置中尝试切换渲染模式。

## 连接问题

### 无法自动检测到模拟器

- 确认模拟器 ADB 调试已开启
- 确认只启动了一个模拟器实例
- 尝试点击"刷新"按钮
- 确认模拟器分辨率设置为 1280x720（横屏）

### 手动连接如何配置？

在连接设置中，点击"自定义"可手动输入 ADB 地址。各模拟器默认端口：

| 模拟器       | 默认 ADB 地址     |
| :----------- | :---------------- |
| MuMu 12      | `127.0.0.1:16384` |
| BlueStacks 5 | `127.0.0.1:5555`  |
| LDPlayer 9   | `127.0.0.1:5555`  |
| 夜神模拟器   | `127.0.0.1:62001` |

### 连接成功但任务无法执行

- 检查游戏是否已安装并更新到最新版本
- 确认已在 MaaKEDR 中选择了正确的资源类型（官服/B 服/TapTap 服）
- 检查 `debug/` 目录下的截图，确认识别图像是否正确

## 任务执行

### Agent 启动超时

首次运行时 MaaKEDR 需要安装 Python 依赖，可能耗时较长。请耐心等待，不要点击停止。若反复超时：

- 检查网络连接是否正常
- 检查 `config/pip_config.json` 中的镜像源是否可用

### 任务未按预期执行

- 确认任务已勾选启用
- 阅读任务的"任务说明"，按要求配置选项
- 确保游戏处于正确的界面（如主菜单或对应功能页面）
- 查看 `maafw.log` 日志文件定位问题

### 资源刷取选项中的关卡列表不全

当前版本仅支持部分预设关卡。如需其他关卡，可参考开发文档中的 Pipeline 指南自行配置。

## 其他

### 如何查看日志？

运行日志位于 `maafw.log`，截图位于 `debug/` 目录下。提交问题反馈时请一并提供这些文件。

### 如何更新 MaaKEDR？

**MXU：** 设置中会出现「更新」相关选项（依赖 `interface.json` 中的 `mirrorchyan_rid`）。  
点击检查更新后，会优先尝试 Mirror 酱；若未购买 CDK 或资源未在 Mirror 登记，一般会回退到 **GitHub Releases**（需能访问 GitHub；可选填 Token 提高限额）。

**MFAAvalonia：** 在软件设置中配置更新源后检查更新即可。

如需手动更新：下载最新版本压缩包，解压到新目录，将旧版本的 `config/` 目录复制到新目录即可保留配置。

## MFAA 使用技巧

### 记住连接与指纹匹配

设置了记住连接后，如果只打开了一个未记住的模拟器就启动 MFAA，已记住的模拟器会变成这个未记住的。如需避免，前往 **设置 → 连接设置**，关闭「使用指纹匹配设备」，即可防止自动切换。

### 多开配置与批量启动

同一目录下的 MFAA 只能启动一个实例。如需同时运行多台模拟器，可在主页配置栏复制或创建多个配置，每个配置分别连接不同的模拟器并设置不同的任务。左侧边栏第二个图标可实时查看所有配置的连接状态。

::: tip
如需启动后自动运行多个配置，可在启动设置中开启「应用启动时批量启动」并选择要启动的配置。
:::

### 自启动游戏

MFAA 支持启动任务后自动打开游戏，有两种方式：

1. **自定义程序**：在任务列表点击「添加任务」，向下找到「自定义程序」添加至列表最上方，在任务设置中填写游戏路径。
2. **连接设置**：确保已开启「连接失败时尝试启动游戏」，然后在启动设置中填写游戏路径即可。

使用模拟器多开时，请确保附加命令中的多开号填写正确。

::: tip
可在启动设置 → 附加命令旁找到多开号快捷设置入口。
:::
