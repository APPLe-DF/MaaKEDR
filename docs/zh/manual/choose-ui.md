# 如何选择 UI

MaaKEDR 提供两种图形界面前端，可根据个人需求选择。

| 对比项         | MFAA                     | MXU                        |
| -------------- | ------------------------ | -------------------------- |
| **特点**       | 功能全面，可调节选项多   | 轻量小巧，界面现代化       |
| **包体大小**   | 较大                     | 较小                       |
| **功能丰富度** | 高                       | 较少                       |
| **适用人群**   | 喜欢高度自定义操作的用户 | 偏好轻量化与简洁界面的用户 |

## MFAA 推荐场景

MFAA 有更多可调节选项且支持多平台，适合需要精细控制的用户。以下功能目前为 MFAA 独有：

- **手动连接调整**：可手动配置 ADB 等连接参数
- **定时设置**：按周期定时启动任务，可单独调整每次启动的配置
- **多配置自启动**：启动后可自动运行多个配置，MXU 仅支持单个

对于复杂的运行环境，MFAA 可以单独调整部分参数让软件正常运行，因此也是大多数用户的首选。

## MXU 推荐场景

MXU 包体更小，界面更现代化，适合追求简洁体验的用户。如果基础功能已满足需求且不需要上述高级特性，MXU 是更轻量的选择。
