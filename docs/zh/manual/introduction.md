# 功能介绍

MaaKEDR 提供以下自动化任务，帮助你更高效地完成《雪松》的日常操作。

---

## 启动游戏

自动启动游戏并进入主界面。

**功能：**

- 启动游戏进程
- 点击"开始游戏"
- 处理每日登录奖励弹窗
- 检测主界面并完成进入

无需额外配置，勾选启用即可。

---

## 领取奖励

一键领取各类奖励。支持按类别独立开关。

**选项：**

| 选项                   | 类型 | 说明                                     |
| :--------------------- | :--- | :--------------------------------------- |
| 派遣任务领取           | 开关 | 是否领取并再次派遣资源派遣任务           |
| 每日/每周/军旅成就奖励 | 开关 | 是否领取每日/每周/军旅成就奖励           |
| 战令通行证奖励         | 开关 | 是否领取战令通行证奖励                   |
| 邮箱奖励               | 开关 | 是否领取邮箱奖励                         |
| 高级账号商店每日奖励   | 开关 | 是否领取高级账号商店免费商品（默认关闭） |

### 派遣任务领取

开启后，MaaKEDR 会：

1. 进入派遣界面
2. 领取已完成派遣的奖励
3. 如开启 **再次派遣**，选择再次派遣
4. 关闭派遣界面

### 每日/每周/军旅成就奖励

每日签到、周常任务和军旅成就的奖励领取。

### 战令通行证奖励

自动领取战令通行证的已解锁奖励。

### 邮箱奖励

自动领取邮件附件。

### 高级账号商店每日奖励

自动进入高级账号商店，领取每日免费商品（仅在有可领取提示时进入，默认关闭）。

---

## 资源刷取

自动刷取资源关卡，支持体力管理。

**选项：**

| 选项     | 类型 | 说明                |
| :------- | :--- | :------------------ |
| 战斗模式 | 选择 | 单次战斗 / 清空体力 |
| 刷取板块 | 选择 | 资源收集 / 技能演练 |
| 资源类型 | 选择 | 见下方              |
| 战斗次数 | 选择 | 1–6 次 / 最大       |

### 战斗模式

- **单次战斗**：按设定的战斗次数刷取，完成后停止
- **清空体力**：持续刷取直至体力耗尽，适合睡前挂机

### 剩余体力刷取

固定为**清空体力**模式的资源刷取，用于把当前剩余体力一次刷完：选择刷取板块后持续刷到体力不足自动退出。通常随「日常 / 活动」预设启用，也可手动开启。

### 资源收集

| 资源类型     | 说明              |
| :----------- | :---------------- |
| 特别军费行动 | 军费/货币关卡     |
| 作战体能训练 | 经验/升级材料关卡 |
| 兵种能力评级 | 兵种晋升材料关卡  |
| 载具对抗演练 | 载具相关材料关卡  |

关卡数量因类型而异，可在选项中具体选择：

- 特别军费行动：1-1 ~ 1-5
- 作战体能训练：2-1 ~ 2-4
- 兵种能力评级：3-1 ~ 3-4
- 载具对抗演练：4-1 ~ 4-5

### 技能演练

| 技能类型     | 说明             |
| :----------- | :--------------- |
| 基础技能演练 | 基础技能升级材料 |
| 专业技能演练 | 高级技能升级材料 |

## 活动关卡与活动商店

自动刷取耀斑活动关卡并兑换活动商店商品。

**活动关卡选项：**

| 选项     | 类型 | 说明                          |
| :------- | :--- | :---------------------------- |
| 活动关卡 | 选择 | EX2-1 / EX2-2 / EX3-1 / EX4-1 |
| 扫荡次数 | 选择 | 1 次 / 2 次 / 3 次 / 最大     |

活动关卡不消耗普通体力，每日扫荡次数上限为 3。使用前需要完成耀斑活动的全部关卡（包括 EX 关卡）。

**活动商店兑换：**

自动进入活动商店的「定额保障」页，逐项购买可用商品，跳过已售罄商品；没有可兑换商品时直接结束任务。

---

## 体力信息

读取主界面当前体力与上限，并提示自然回满时间。任务默认开启，位于每日任务链末尾。

任务会自动：

1. 确认位于主界面（不在主页时点击主页按钮返回）
2. 读取主界面体力数字
3. 计算并输出回满时间（体力达到自然恢复上限后不再随时间恢复，会明确提示）

---

## 玩家对战

自动进行玩家对战（PVP），支持多场次循环。

**选项：**

| 选项     | 类型 | 说明                               |
| :------- | :--- | :--------------------------------- |
| 战斗次数 | 选择 | 1–6 次（6 次用于高级账号失败保护） |

MaaKEDR 会自动：

1. 进入玩家对战界面
2. 匹配并开始战斗
3. 识别战斗结果
4. 重复直至达到设定次数

> [!NOTE]
>
> PVP 战斗结果受游戏内阵容和练度影响，MaaKEDR 仅自动化操作流程，不保证胜利。

---

## 任务预设

预设会把一组常用任务一键勾选，方便不同场景：

- **日常**：启动游戏 → 资源刷取 → 领取奖励 → 剩余体力刷取 → 玩家对战 → 领取奖励 → 体力信息
- **活动**：启动游戏 → 活动关卡刷取 → 活动商店兑换 → 资源刷取 → 领取奖励 → 剩余体力刷取 → 玩家对战 → 领取奖励 → 体力信息

选择「活动」预设时，「活动关卡刷取 / 活动商店兑换」会默认开启；「日常」预设不包含活动任务。
