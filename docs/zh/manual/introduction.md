# 功能介绍

MaaKEDR 提供以下自动化任务，帮助你更高效地完成《雪松》的日常操作。

## 通用说明

- **前置条件**：除「启动游戏」外，各任务都要求游戏已运行并处于可操作状态。任务入口会先确认当前是否在**主界面**；不在主界面时，由通用回主页枢纽依次尝试关闭「获得物品」弹窗、点击顶部主页按钮、点击通用返回按钮，回到主页后自动继续原流程。枢纽最多尝试 10 轮，仍无法回到主页时任务才会失败。
- **任务顺序**：任务按列表从上到下依次执行。推荐顺序为「启动游戏 → 刷取 / 活动 → 领取奖励 → 剩余体力刷取 → 玩家对战 → 剩余奖励领取 → 体力信息」，见下方 [任务预设](#任务预设)。
- **选项**：每个任务的选项都在图形界面的 **任务设置** 中配置，含义见对应章节；未提及的选项保持默认即可。

---

## 启动游戏

自动启动游戏并进入主界面。

**前置条件：** 游戏已在模拟器中安装。

**功能：**

- 启动游戏进程
- 点击"开始游戏"
- 处理每日登录奖励弹窗
- 检测主界面并完成进入

**选项：** 无，勾选启用即可。

> [!NOTE]
>
> 冷启动（游戏未运行）与热启动（游戏已在运行）都支持。建议将该任务放在任务链首位。

---

## 领取奖励

一键领取各类奖励。支持按类别独立开关。

**前置条件：** 游戏已登录并处于主界面（任务会先确认主页再逐项领取）。

**选项：**

| 选项                   | 类型 | 默认 | 说明                                                           |
| :--------------------- | :--- | :--- | :------------------------------------------------------------- |
| 派遣任务领取           | 开关 | 开   | 是否进入派遣界面领取已完成派遣的奖励                           |
| 再次派遣               | 开关 | 开   | 「派遣任务领取」开启后出现：领完是否再次派遣，关闭则直接关界面 |
| 每日/每周/军旅成就奖励 | 开关 | 开   | 是否领取每日/每周/军旅成就奖励                                 |
| 战令通行证奖励         | 开关 | 开   | 是否领取战令通行证奖励                                         |
| 邮箱奖励               | 开关 | 开   | 是否领取邮箱奖励                                               |
| 高级账号商店每日奖励   | 开关 | 关   | 是否领取高级账号商店免费商品                                   |

### 派遣任务领取

开启后，MaaKEDR 会：

1. 进入派遣界面
2. 领取已完成派遣的奖励
3. 如开启 **再次派遣**，选择再次派遣
4. 关闭派遣界面

### 每日/每周/军旅成就奖励

每日签到、周常任务和军旅成就的奖励领取。

### 战令通行证奖励

自动领取战令通行证的已解锁奖励。

### 邮箱奖励

自动领取邮件附件。

### 高级账号商店每日奖励

自动进入高级账号商店，领取每日免费商品（仅在有可领取提示时进入，默认关闭）。

---

## 剩余奖励领取

任务链后段的补充领取：领取进行中新获得的奖励（如 PVP 奖励，通常进邮箱）。

**前置条件：** 游戏处于主界面；通常由任务预设放在「玩家对战」之后执行。

**选项：** 与 [领取奖励](#领取奖励) 完全相同（派遣、成就、战令、邮箱、高级账号商店五项开关）。

> [!TIP]
>
> 「领取奖励」与「剩余奖励领取」用的是同一套流程，区别只在于放在任务链中的位置：前者在前段清理已有奖励，后者在后段收拾运行过程中新产生的奖励。

---

## 资源刷取

自动刷取资源关卡，支持体力管理。

**前置条件：** 游戏处于主界面；对应关卡已解锁（技能演练中的锁定关卡会被识别并跳过）。

**选项：**

| 选项     | 类型 | 默认            | 说明                             |
| :------- | :--- | :-------------- | :------------------------------- |
| 战斗模式 | 选择 | 单次战斗        | 单次战斗 / 清空体力              |
| 战斗次数 | 选择 | 1 次            | 1–6 次 / 最大（仅单次战斗模式）  |
| 刷取板块 | 选择 | 资源收集        | 资源收集 / 技能演练              |
| 资源类型 | 选择 | 特别军费行动    | 资源收集板块下可选，见下方       |
| 技能类型 | 选择 | 基础技能演练    | 技能演练板块下可选，见下方       |
| 关卡选择 | 选择 | 1-1 / 基础训练1 | 随资源类型或技能类型变化，见下方 |

### 战斗模式

- **单次战斗**：按设定的战斗次数刷取，完成后停止
- **清空体力**：持续刷取直至体力耗尽，适合睡前挂机

### 资源收集

| 资源类型     | 说明              |
| :----------- | :---------------- |
| 特别军费行动 | 军费/货币关卡     |
| 作战体能训练 | 经验/升级材料关卡 |
| 兵种能力评级 | 兵种晋升材料关卡  |
| 载具对抗演练 | 载具相关材料关卡  |

关卡数量因类型而异，可在选项中具体选择：

- 特别军费行动：1-1 ~ 1-5
- 作战体能训练：2-1 ~ 2-4
- 兵种能力评级：3-1 ~ 3-4
- 载具对抗演练：4-1 ~ 4-5

### 技能演练

| 技能类型     | 说明             | 关卡           |
| :----------- | :--------------- | :------------- |
| 基础技能演练 | 基础技能升级材料 | 基础训练 1 ~ 3 |
| 专业技能演练 | 高级技能升级材料 | 专业训练 1 ~ 3 |

> [!NOTE]
>
> 技能演练的关卡需要先在游戏内解锁；处于锁定状态时任务会识别到锁图标并停止进入该关卡。

## 剩余体力刷取

固定为**清空体力**模式的资源刷取，用于把执行到此步时的剩余体力一次刷完。

**前置条件：** 游戏处于主界面；已选择刷取板块。

**选项：**

| 选项     | 类型 | 默认            | 说明                     |
| :------- | :--- | :-------------- | :----------------------- |
| 刷取板块 | 选择 | 资源收集        | 资源收集 / 技能演练      |
| 资源类型 | 选择 | 特别军费行动    | 资源收集板块下可选       |
| 技能类型 | 选择 | 基础技能演练    | 技能演练板块下可选       |
| 关卡选择 | 选择 | 1-1 / 基础训练1 | 与资源刷取相同的关卡范围 |

> [!NOTE]
>
> 本任务使用**独立于「资源刷取」的一套选项**，可以刷取与「资源刷取」不同的关卡。它默认不勾选，通常随「日常 / 活动」预设启用；刷到体力不足时会自动减次退出。

---

## 活动关卡与活动商店

自动刷取耀斑活动关卡并兑换活动商店商品。

**前置条件：** 已解锁耀斑活动；活动关卡需要先完成活动的全部关卡（包括 EX 关卡）才能扫荡。

**活动关卡选项：**

| 选项     | 类型 | 默认  | 说明                          |
| :------- | :--- | :---- | :---------------------------- |
| 活动关卡 | 选择 | EX2-1 | EX2-1 / EX2-2 / EX3-1 / EX4-1 |
| 扫荡次数 | 选择 | 3 次  | 1 次 / 2 次 / 3 次 / 最大     |

活动关卡不消耗普通体力，每日扫荡次数上限为 3。

**活动商店兑换：**

自动进入活动商店的「定额保障」页，逐项购买可用商品，跳过已售罄商品；没有可兑换商品时直接结束任务。

> [!NOTE]
>
> 两个活动任务都需要从游戏主页进入活动，结束后也都会返回游戏主页，因此可以安全地插在任务链中间。

## 体力信息

读取主界面当前体力与上限，并提示自然回满时间。

**前置条件：** 游戏处于主界面（任务会自动回主页）。建议作为**最后一个任务**运行。

**选项：** 无。

任务会自动：

1. 确认位于主界面（不在主页时自动回主页：点主页按钮 / 通用返回）
2. 读取主界面体力数字
3. 计算并输出回满时间（体力达到自然恢复上限后不再随时间恢复，会明确提示）

> [!NOTE]
>
> 体力按 4 分钟 1 点的速度自然恢复；读取失败时会重试，仍失败则本次跳过输出，不影响其它任务。

## 玩家对战

自动进行玩家对战（PVP），支持多场次循环。

**前置条件：** 游戏处于主界面；今日对战次数未用尽（次数用尽时任务会提示并返回主页）。

**选项：**

| 选项     | 类型 | 默认 | 说明                               |
| :------- | :--- | :--- | :--------------------------------- |
| 战斗次数 | 选择 | 1 次 | 1–6 次（6 次用于高级账号失败保护） |

每天有 5 次 PVP 机会；高级账号含首次失败保护（首次失败不消耗次数），最多可打 6 场，打满请选「6次」。

MaaKEDR 会自动：

1. 进入玩家对战界面
2. 匹配并开始战斗
3. 识别战斗结果
4. 重复直至达到设定次数

> [!NOTE]
>
> PVP 战斗结果受游戏内阵容和练度影响，MaaKEDR 仅自动化操作流程，不保证胜利。对手选择上会优先挑选等级最低的一位。

---

## 任务预设

预设会把一组常用任务一键勾选，方便不同场景：

- **日常**：启动游戏 → 资源刷取 → 领取奖励 → 剩余体力刷取 → 玩家对战 → 剩余奖励领取 → 体力信息
- **活动**：启动游戏 → 活动关卡刷取（EX2-1 / EX2-2 / EX3-1 / EX4-1 各一次）→ 活动商店兑换 → 资源刷取 → 领取奖励 → 剩余体力刷取 → 玩家对战 → 剩余奖励领取 → 体力信息

选择「活动」预设时，「活动关卡刷取 / 活动商店兑换」会默认开启，四个活动关卡的扫荡次数都设为「最大」；「日常」预设不包含活动任务。
