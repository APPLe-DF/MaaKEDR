# Choosing a UI

MaaKEDR ships with two GUI frontends. Choose the one that fits your needs.

| Aspect           | MFAA                              | MXU                           |
| ---------------- | --------------------------------- | ----------------------------- |
| **Style**        | Feature-rich, highly configurable | Lightweight, modern interface |
| **Package size** | Larger                            | Smaller                       |
| **Feature set**  | Extensive                         | Basic                         |
| **Best for**     | Users who want full control       | Users who prefer simplicity   |

## When to Choose MFAA

MFAA offers more configurable options and multi-platform support. The following features are currently MFAA-only:

- **Manual connection tuning**: Fine-tune ADB and other connection parameters
- **Scheduled tasks**: Run tasks on a timer with per-run configuration
- **Multi-config auto-start**: Launch multiple configs on startup (MXU only supports one)

For complex environments, MFAA allows adjusting individual parameters to keep things running — it's the default choice for most users.

## When to Choose MXU

MXU has a smaller package size and a modern interface, ideal for users who prefer a clean, simple experience. If the basic features cover your needs and you don't require the advanced options above, MXU is a lighter alternative.
